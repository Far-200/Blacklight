# Blacklight

Reveal what attackers would find before they do.

Blacklight analyzes source code and web projects for security vulnerabilities, explains why they're exploitable, and generates actionable remediation reports.

## Features (Coming Soon)

- Static analysis for source code vulnerabilities
- Dependency and configuration scanning
- Clear severity ratings and explanations
- Actionable remediation guidance
- Exportable security reports

## Disclaimer

Blacklight is intended for authorized security testing and defensive use only.
